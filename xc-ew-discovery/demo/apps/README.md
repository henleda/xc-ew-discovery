# Demo apps

The polyglot demo app that M1 and M4 exercise goes here: a few services in
different languages calling each other over HTTP, HTTP/2, and gRPC, plaintext and
TLS, in namespace `demo`. `make deploy-demo` applies everything in this directory.

Not committed yet. Manifests land with M1 (see `docs/MILESTONES.md`). Until then
`make deploy-demo` has nothing to apply.
